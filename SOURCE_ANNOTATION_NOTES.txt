PX68K Tab5 Build 6.00 - Source Annotation Convention

This package has the same production logic as Build 6.00 Stable Release.
Comments were added to make Tab5-specific changes easy to identify during future maintenance.

Convention
----------
- Modified upstream PX68K files contain a short English intent note near the file header.
- New Tab5-specific files are explicitly marked as port-specific implementation.
- High-risk architectural changes (CPU split, Musashi batching, audio ownership, USB pad persistence,
  HDS/HostFS boot, and CPU0 composition) also have local intent comments next to the relevant code.
- Each added annotation is signed: Layer8 Aug/17/2026

The comments describe why the change exists, not merely what the code does.
No emulator algorithm or runtime setting was intentionally changed by this annotation pass.
